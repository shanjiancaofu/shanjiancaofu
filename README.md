## 简短介绍

主要使用 C/C++，平时在 Linux、Jetson 和 STM32 上做系统开发。
关注设备树、传感器接入、CAN FD，以及从硬件联调到软件交付的完整过程。

---

## 当前关注

- Jetson Orin Nano 与 STM32G474 协同控制，打通 CAN FD 通信和电机控制
- 基于 Jetson Orin 的智能座舱系统，以及设备接入和系统整合
- C/C++ 工程化开发、底层调试和开发工具改进
